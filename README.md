# Interactive Web Dev Quiz App

A modern, responsive quiz application built with React and Vite. This project was designed to master complex React state management, dynamic rendering with `.map()`, and conditional rendering across multiple screens.

## 🚀 Live Demo
[View the live site here](PASTE_YOUR_VERCEL_LINK_HERE) 

## ✨ Features
- **Multi-Screen Flow:** Seamlessly transitions between the Start Screen, Quiz Screen, and Results Screen using conditional rendering.
- **Dynamic Rendering:** Uses `.map()` to render an array of answer options dynamically.
- **Score Tracking:** Uses multiple `useState` hooks to track the current question, selected answer, and final score.
- **Visual Feedback:** Selected answers highlight in blue. The "Next" button only appears after an answer is chosen.
- **Fully Responsive:** Fluid layout that adapts perfectly to mobile, tablet, and desktop screens.

## 🛠️ Technologies Used
- React (v18+)
- Vite
- CSS3 (Flexbox, CSS Variables, Conditional Classes)
- Git & GitHub
- Vercel (Deployment)
